# Outfit

Variable Outfit from the official Google Fonts repository. Downloaded 2026-09-22.

- Source: https://raw.githubusercontent.com/google/fonts/main/ofl/outfit/Outfit%5Bwght%5D.ttf
- License: SIL Open Font License 1.1, in `OFL-Outfit.txt`.
- Source TTF SHA-256: `fc7287273e66929776e2ba54f144fe699080bec29f61bf649d70d871468aeade`
- WOFF2 SHA-256: `6a320f5de34e460726f2c7ebfe17df5f2c96346332ceac10fe28f799808d1e0f`

Converted to WOFF2 with fontTools, retaining all glyphs and the full 100-900 weight axis. The app uses 300 for page headings, 400 for body text, 500 for labels, and 600 for selected values and emphasis. No external font requests are required.
