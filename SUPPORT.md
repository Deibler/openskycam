# Getting help

- **Setting up or using openskycam:** start with the [documentation](https://docs.openskycam.org). `npm run setup -- --check` checks every part of a deployment and says what is wrong.
- **Questions, ideas, and cameras that work:** [Discussions](https://github.com/Deibler/openskycam/discussions).
- **Something does not work as documented:** [open a bug report](https://github.com/Deibler/openskycam/issues/new/choose) with the output of `npm run setup -- --check`.
- **A security vulnerability:** report it privately, as [SECURITY.md](SECURITY.md) describes. Never in a public issue.

openskycam is maintained by one person in their own time, so answers can take a few days.
